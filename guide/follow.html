Copy Trading ​

Copy trading is the platform's social trading product: a lead trader creates a trading plan and generates a copy code, users follow with one tap using the code, and the system opens and settles positions for everyone at the set time.

Overall flow ​

text
Admin grants "lead trading" permission to a user
    ↓
The lead trader creates a plan on the user side → a dedicated copy code is generated
    ↓
Users enter the code → follow with one tap (no need to watch the market)
    ↓
At the set time, the system opens positions in batch
    ↓
After settlement, each user's profit or loss is written back automatically

What operators do ​

1. Grant lead-trading permission ​

Not every user can issue copy codes. You must grant lead-trading permission to specific users in the admin console; users without it cannot create plans.

2. Control the daily code quota ​

The admin console can limit how many copy codes a lead trader can issue per day, to prevent abuse.

3. Copy-trading management ​

The admin console provides full copy-trading records: who issued the code, who followed, and the results of opening and settlement.

Funds safety ​

  • The whole process is managed by the system, with every movement of funds recorded
  • A failed follow is refunded immediately to its source — there is never a case where funds are deducted but no position is opened

FAQ ​

A user says the copy code is invalid? Check: ① whether the code has expired; ② whether the plan has already reached its opening time (plans that have opened no longer accept new followers); ③ whether the code was mistyped.

A user followed but no position was opened? Check that entry's status in the copy-trading records. A failed follow is refunded to its source, and the user can see the refund in their ledger.
