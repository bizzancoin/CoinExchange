On this page

Site Configuration ​

Most of what users see — menus, icons, featured coins, VIP tiers and so on — is not hard-coded. Operators adjust it under "Basic Configuration" in the admin console. Once saved, it takes effect the next time the user side is opened, with no engineering work and no new release.

This page first goes through each tab under "Basic Configuration", then explains the eight integration cards on the "Third-Party Configuration" page.

Side menu ​

The list of entries on the user side's "Me" page. For each item you can configure the name, icon, link target, order and on/off switch.

Turning an item off removes that entry from the user side.

The key here decides which page the app opens

Each item has a key. The app uses the key to decide which native page to open — with the correct key, tapping it opens a smooth native page; if the key is wrong or the item is not configured, the entry simply does not exist in the app.

Common keys with native pages (the app will not recognize a mistyped key):

keyFeature
serviceLive chat (see Customer Service)
helperHelp center
languageLanguages
primary / advancedBasic verification / identity verification
certifiedEmail verification
bankBind bank card
tardPwd / loginPwdFund password / login password
termsServiceTerms of service
paperWhite paper

If a feature entry is missing in the app, first check here whether its key is configured and enabled — that is much faster than suspecting the app.

Home shortcuts work the same way

The key rules for the home shortcut grid are the same as here (e.g. financial wealth management, pledge staking, subscription token subscription, download_center download center, promotion_center referral center).

Bottom bar ​

The user side's bottom navigation bar (Home / Markets / Trade / Assets, etc.). You can configure the name, selected and unselected icons, link target, order and on/off switch.

Note

The bottom bar is the backbone of the user side. Keep at least Home and Assets — turning everything off leaves users unable to navigate.

Home shortcuts ​

The grid of quick-access entries at the top of the home page. Configured the same way as the side menu.

Featured coins ​

Which coins the home market list shows by default, and in what order.

Asset tabs ​

The section tabs on the user's asset page (e.g. spot assets, contract assets, wealth assets). Turn one off and the asset page no longer shows that section.

Product configuration ​

Master switches for each trading product. Turning one off hides the corresponding entry on the user side.

Platform logo ​

The platform logo and icons in each size (57×57 / 72×72 / 120×120 / 144×144).

VIP tiers / VIP description ​

  • VIP tiers: the threshold for each tier
  • VIP description: the benefit text shown to users

Download links ​

The list of download entries shown in the user side's "Download Center"; each item has a name, download URL, order and on/off switch.

How this differs from app auto-update

The download center is for new users to install the app; existing users are updated through auto-update, configured under "App Version Update". The two are independent, but we recommend pointing them at the same version.

App version update ​

Controls whether users with the app installed receive a new-version prompt. This is a super-admin-only setting. See App Releases.

Sign-up and login ​

Controls which methods users can register and log in with (email / phone / username / wallet address), and the initial credit score of new users.

Captcha / time zone ​

  • Captcha: settings for the image captcha
  • Time zone: the platform's reference time zone, affecting time display in the admin console and on the user side

White paper ​

The URL of the platform white paper.

Tip

Use a web page or PDF. If it points to a .doc file, users may not be able to preview it directly.

Notification sounds ​

Sounds played in the admin console when deposit / withdrawal events arrive.

Admin IP control ​

Restricts which IPs can access the admin console. Super-admin-only setting.

High-risk operation

A misconfiguration can lock you out of the console as well. Before changing it, make sure the outbound IP you are currently using is on the allowlist.

Data masking ​

Masking switches for each business module, with a master switch and per-product sub-switches.

Third-party configuration ​

This is a separate page from "Basic Configuration". It holds the platform's integration details with external services — rarely changed, but with a large impact if wrong. We recommend that a super administrator or one designated operator owns it.

CardWhat it isWho can change it
SMSAccount, password and endpoint of the SMS provider, used for phone verification codesOperators with configuration permission
EmailSender account, password, server address and port, used for email verification codes and notificationsOperators with configuration permission
OSSDomain, account and bucket of object storage (images, attachments); user avatars, KYC documents and chat images are stored hereOperators with configuration permission
TG botDeposit / withdrawal alert bot that pushes deposit and withdrawal events to the operators' Telegram group. The group ID is written automatically when the bot first joins; no need to fill it inOperators with configuration permission
UDUNGateway URL, merchant ID, merchant key and callback URL of the UDUN deposit/withdrawal channelSuper administrator only
Payment gatewayChoose one: whether the deposit channel currently active for users is "UDUN" or "TokenPay"Super administrator only
TokenPayService URL, ApiToken, callback URL and enable switch of the TokenPay channel. See Deposits & WithdrawalsSuper administrator only
Live chatSupport bot token, support group ID, callback URL and secret. See Customer ServiceOperators with configuration permission

The two Telegram bots cannot be shared

The "TG bot" (alerts) and "Live chat" (support) must be two different bots. Sharing one token makes them steal each other's messages, and neither receives everything.

Secrets are not displayed

After saving, password and key fields no longer show the original value (only that it is set). Keep a backup elsewhere before changing them; otherwise, if you enter it wrong, you will have to request it from the provider again.

Before switching the payment gateway

First make sure the target channel's card is filled in and enabled, then switch "Payment gateway". Switching to a channel that is not configured makes deposits fail immediately for users.
