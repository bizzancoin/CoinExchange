本页目录

站点配置 ​

用户端看到的菜单、图标、首页币种、VIP 等级等，绝大部分不写死在代码里，而是由运营在后台的「基础配置」中调整。改完保存，用户端重新打开即生效，不需要技术介入、不需要重新发版。

本页先逐项说明「基础配置」下的各个标签页，末尾再说明「第三方配置」页里的八张接入卡片。

侧边栏配置 ​

用户端「我的」页面里的功能入口列表。可配置每一项的名称、图标、跳转地址、排序与开关。

关掉某一项，用户端就不再显示该入口。

这里的 key 决定 App 打开哪个页面

每一项都有一个 key。App 是靠 key 来决定用哪个原生页面的 —— key 填对了，点进去是流畅的原生页； key 填错或没配这一项，App 里就直接没有这个入口。

已实现原生页的常用 key（填错 App 认不出来）：

key对应功能
service在线客服（详见在线客服）
helper帮助中心
language多语言
primary / advanced初级认证 / 实名认证
certified邮箱认证
bank绑定银行卡
tardPwd / loginPwd资金密码 / 登录密码
termsService服务条款
paper白皮书

如果 App 里找不到某个功能入口，先来这里确认对应的 key 有没有配、有没有开， 这比怀疑 App 出问题要快得多。

首页金刚区同理

「金刚区」的 key 规则与这里一致（如 financial 理财、pledge 质押、subscription 申购、 download_center 下载中心、promotion_center 推广中心）。

底部栏设置 ​

用户端底部导航栏（首页 / 行情 / 交易 / 资产 等）。可配置名称、选中与未选中的图标、跳转地址、排序与开关。

注意

底部栏是用户端的骨架。至少保留首页与资产，全部关闭会让用户无法导航。

金刚区 ​

首页顶部的宫格快捷入口区。配置项与侧边栏一致。

首页币种设置 ​

首页行情列表默认展示哪些币种、以什么顺序展示。

资产 Tab 设置 ​

用户资产页的分区标签（如现货资产、合约资产、理财资产等）。关掉某一个，资产页就不再显示该分区。

玩法配置 ​

各交易玩法的总开关。关掉某一项，用户端对应入口即隐藏。

平台 logo 设置 ​

平台 Logo 及各尺寸图标（57×57 / 72×72 / 120×120 / 144×144）。

VIP 等级设置 / VIP 说明 ​

  • VIP 等级设置：各等级的门槛
  • VIP 说明：展示给用户看的等级权益说明文案

下载地址配置 ​

用户端「下载中心」里展示的下载入口列表，每一项含名称、下载地址、排序与开关。

与 App 自动更新的区别

下载中心是给新用户装 App 用的；已经装了 App 的老用户走的是自动更新，配置在「App版本更新」里。两者互不影响，但建议保持指向同一个版本。

App 版本更新 ​

控制已安装 App 的用户是否收到新版本提示。这是超级管理员专属配置，详见 App 版本发布。

登录注册配置 ​

控制用户可以用哪些方式注册与登录（邮箱 / 手机 / 普通 / 钱包地址），以及新用户的初始信用分。

验证码设置 / 时区设置 ​

  • 验证码设置：图形验证码的相关配置
  • 时区设置：平台的时区基准，影响后台与用户端的时间显示

白皮书配置 ​

平台白皮书文件地址。

提示

建议放网页或 PDF。如果配成 .doc 文件，用户端可能无法直接预览。

提示音配置 ​

后台收到充值 / 提现事件时的提示音。

后台 IP 控制 ​

限制哪些 IP 可以访问运营后台。超级管理员专属配置。

高风险操作

配置错误会把自己也挡在后台之外。修改前请确认当前使用的出口 IP 已在白名单内。

打码配置 ​

各业务模块的打码（数据脱敏）开关，含总开关与各玩法子开关。

第三方配置 ​

与「基础配置」是两个不同的页面。这一页集中放平台与外部服务的接入信息，改动频率低、但改错影响面大，建议由超级管理员或指定的一位运营负责。

卡片是什么谁能改
短信配置短信服务商的账号、密码与请求地址，用于手机验证码有配置权限的运营
邮箱配置发信邮箱的账号、密码、服务器地址与端口，用于邮件验证码与通知有配置权限的运营
OSS 配置对象存储（图片、附件）的域名、账号与存储桶，用户上传的头像、实名资料、客服图片都存在这里有配置权限的运营
TG 机器人充值 / 提现告警机器人，把充提事件推送到运营的 Telegram 群。群组 ID 由机器人首次接入时自动写入，不用手填有配置权限的运营
优盾配置优盾充提通道的网关地址、商户号、商户密钥与回调地址仅超级管理员
支付网关二选一：当前对用户生效的入金通道是「优盾」还是「TokenPay」仅超级管理员
TokenPay 配置TokenPay 通道的服务地址、ApiToken、回调地址与启用开关，详见充值与提现仅超级管理员
在线客服客服机器人 Token、客服群组 ID、回调地址与密钥，详见在线客服有配置权限的运营

两个 Telegram 机器人不能共用

「TG 机器人」（告警）与「在线客服」（客服）必须是两个不同的机器人。共用一个 Token 会让两边互相抢消息、都收不全。

密钥不回显

密码、密钥类字段保存后页面不会再显示原值（只显示已设置）。改动前请先在别处留好备份，否则填错只能重新向服务商索取。

切换支付网关前

先确认目标通道的卡片已填写并启用，再切「支付网关」。切到一个没配好的通道，用户端的充值会立刻失败。
