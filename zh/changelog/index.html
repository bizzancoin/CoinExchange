入金通道升级：任意金额到账 + 多重到账核验
  • 任意金额到账：对接支付服务新版能力，用户无需预先下单填额，链上实付多少即入账多少，减少因金额不符导致的掉单与人工补单。
  • 资金入口多重核验：到账需依次通过签名校验、订单归属与收款地址一致性校验，并由平台主动向支付服务端二次核对后才入账；同一笔链上交易只会入账一次。签名算法升级为 HMAC-SHA256——更高级别的签名算法，进一步保障资金安全。
  • 全端同步：网页、H5、App 三端同时上线，报错提示支持十余种语言。

价值：在不增加运营人力的前提下，提升入金转化率，并把「伪造到账」类风险挡在机制层面。

现货委托：后台人工成交与资金校验加固

新增限价委托后台人工成交：长期未成交的限价单，后台可按其委托价格完成成交。手续费照常收取，用户端记录与正常成交一致；操作全程留痕，可追溯操作人与时间。 外汇、黄金、股票、指数等标的同样适用。

同期完成一轮下单与结算的资金校验加固：

  • 委托金额以服务端计算为准，不再采用客户端提交的金额，杜绝金额与实际下单量不一致的情况。
  • 扣款与冻结全面引入余额校验，余额不足时操作直接失败并提示，不会产生异常账目。
  • 冻结资金按笔精确释放，同一币种存在多笔委托时，各笔委托的冻结互不影响。

价值：长期挂单有了明确的处理方式；同时资金链路的每一次扣减都有独立校验兜底， 账户资金的准确性由机制保障，而非依赖调用方的正确性。

App v1.0.0
首个正式版本

我们没有采用"网页套壳"的做法，而是选择 Flutter 跨平台原生技术路线，从登录、行情、K 线、 下单、结算到资产、充提，全部以原生页面重写。相比套壳方案，它带来三点确定性的差异： 启动更快、操作跟手、可正式上架应用商店。

一、交易核心：全部原生 ​

  • 行情与 K 线：接入 TradingView 专业图表，多周期切换、指标齐全；行情价格实时推送， K 线顶部报价已做到亚秒级更新。
  • 秒合约：下单 → 倒计时 → 自动结算全链路原生，倒计时以服务端定盘时刻为唯一基准， 所见即真实结算时点。
  • U 本位永续合约：划转、开仓、持仓、平仓完整闭环，市价 / 限价、盘口十档、实时盈亏一屏可见。
  • 币币现货 与 闪兑：两种交易方式并行，适配不同习惯的用户。
  • TradFi（外汇 / 商品 / 股票 / 指数）：在传统金融品类上提供与数字资产一致的交易体验， 品类与品种均可由平台后台配置。

二、资产与资金 ​

  • 资产总览、账户分布（平台 / 理财 / 合约分账户一目了然）、划转、充值、提现、充提记录、 资金流水，全部原生化。
  • 充值页按币种正确标识 TRC20 / ERC20 / BEP20 等网络，并把"充错链无法找回"的提示前置到操作之前。
  • 资产页完整展示全部持仓币种，金额显示去掉冗余小数位，同时保留小额资产精度。

三、理财与增值 ​

  • 理财 / 质押 / 助力贷 / 挖矿 全部原生页面。
  • 申购（打新）：项目列表、认购、订单与状态流转全流程原生。
  • 跟单 / 带单：输入跟单码一键跟投，带单员发码带单，全流程系统托管。

四、账户与安全 ​

  • 注册 / 登录 / 找回密码：App 端具备完整的独立注册能力，无需再跳转网页。
  • 实名认证、邮箱认证、银行卡、条款协议、VIP 等级、在线客服全部原生化。
  • 网络层启用 HTTPS + HTTP/2，接口响应更快；登录态失效即时识别并安全跳转。

五、运营可配置 ​

平台后台即可控制 App 的呈现，无需发版：

  • 底部导航 Tab、首页服务宫格、「我的」菜单、资产页 Tab 均由后台配置驱动；
  • 公告、帮助中心、下载中心、白皮书、推广中心内容后台可维护；
  • 邀请码深链归因：用户通过推广链接安装 App 后，邀请关系自动带入，代理推广体系在 App 上完整延续。

六、多语言 ​

内置 7 种语言：简体中文、繁体中文、英语、日语、韩语、越南语、泰语。 语言列表由后台控制，可按运营区域开关。

新增玩法：跟单交易

上线跟单码玩法，为平台引入社交化交易场景。

  • 带单员发起带单计划并生成专属跟单码；
  • 用户输入跟单码即可一键跟投，无需盯盘；
  • 到点由系统统一批量建仓，结算后自动回写各自盈亏；
  • 后台提供完整的跟单管理与带单权限、每日发码额度管控。

价值：降低新手参与门槛，提升用户活跃与留存，同时为平台沉淀带单员生态；全流程系统托管，资金动作全程留痕，跟投失败即时原路退款。

08/022026
交易稳定性：极端行情下的风控升级

针对"极端行情、网络抖动、行情源中断"等异常场景，我们对合约清算与秒合约结算体系做了专项加固。

  • 行情失真防护：引入报价新鲜度校验。行情链路中断时，残留的陈旧报价会被识别并拒绝采信，系统主动暂停该标的的清算与条件单触发，待行情恢复后按真实市价重新判定。原则明确：清算延迟可以接受，错误清算不可接受。
  • 重复结算防护：用户平仓、止盈止损、强制平仓、后台人工处理四条路径共享同一套仓位所有权机制，同一笔仓位只会被结算一次，杜绝重复结算与重复出入金。
  • 订单不悬挂：期权类订单到期时若行情暂时缺失，系统采用"有限等待 + 超时兜底"策略——先等待行情自愈，超时则撤单并原路退还本金并留痕，绝不出现"扣了钱既不结算也不退款"的悬挂订单。
  • 时间显示一致：客户端倒计时改为以服务端到期时刻为唯一基准，并提供授时校准，解决了客户端计时与真实定盘时刻的系统性偏差，用户所见即真实结算时点。
  • 横向扩展就绪：结算任务引入全局互斥机制，为后续多节点扩容打好基础，扩容不会带来重复结算风险。

价值：系统在依赖失效时的行为，从"静默失败、带病运行"升级为"显式降级、可追溯、资金动作幂等"。本轮加固未改变任何盈亏计算口径与业务规则，改变的只是异常场景下的行为边界。

资金安全：全面安全审计与加固

我们对平台进行了一次覆盖登录鉴权、资金链路、配置与密钥的全面安全审计，并完成全部加固。

  • 账户接入安全：关闭了存在风险的免密登录路径；恢复并强化后台的谷歌二次验证，杜绝"开关开启但实际不校验"的情况；管理后台的关键配置接口全部纳入权限管控。
  • 资金账目一致性：提现、下单、闪兑、充值到账、退款、后台调账等全部资金动作，改造为原子化事务处理，从机制上杜绝高并发下的余额异常与重复入账。
  • 权限边界收口：用户侧接口一律以登录身份为准，杜绝越权访问或修改他人资料与地址。
  • 重复发放防护：理财结算、活动奖励等派发环节增加幂等控制，杜绝重复发放与收益统计偏差。
  • 密钥与外联治理：清理了系统中遗留的对外数据通道与硬编码凭据，生产密钥全面外部化管理，关闭对外暴露的运维监控入口并移除弱口令。
  • 账号防护：图形验证码、找回密码失败次数限制、注册初始密码策略全面收紧。

价值：平台在正式运营前完成了一次系统性的安全体检与整改，资金账目的准确性与账户的不可冒用性得到机制级保障，而非依赖人工事后核查。

支付与入金：更快、更省心的充值体验

新增 TokenPay 数字资产入金通道，与原有通道并行，平台可按需切换，互不影响。

  • 专属收款地址：每位用户拥有稳定的专属充值地址，反复充值无需重新获取。
  • 下单式充值：填写金额即生成应付币数、收款二维码与有效期倒计时，所见即所付，杜绝"充错金额、充错链"。
  • 链上实收自动到账：以链上实际到账金额为准自动入账，无需人工审核介入，到账更快、对账更准。
  • 充值页网络标识修正：按所选币种正确展示 TRC20 / ERC20 / BEP20 等网络，从源头避免用户充错链导致的资产损失。

价值：入金环节从"人工确认"走向"全自动闭环"，缩短用户等待，降低客服与财务对账成本，同时具备双通道容灾能力——单一通道异常时可即时切换，业务不中断。
