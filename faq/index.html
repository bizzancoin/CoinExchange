FAQ ​

Every question on this page is one that has actually come up.

Configuration ​

I changed a setting in the admin console, but nothing changed on the user side? ​

User-side configuration is fetched once at startup. After operators make a change:

  • App: users must fully quit the app and reopen it (sending it to the background doesn't count); the new configuration arrives on the next launch
  • Web (PC / H5): just refresh the page

The setting is filled in, but the user side shows "No data"? ​

First check whether the item's switch is on. In list-type settings (bottom bar, home shortcuts, side menu, download links, etc.), disabled items are not sent to the user side; if the whole group is off, the user side is empty.

Links in the download center do nothing when tapped? ​

Check that the download URL includes the http:// or https:// prefix. A bare domain (e.g. example.com) is treated as a relative in-site path on some clients, so tapping does nothing.

The white paper won't open / shows a blank page? ​

Configure the white paper as a web page or PDF. If it's a .doc file, the user side's embedded browser can't render it, and it shows up blank.

App ​

A user can't install the app — "App not installed"? ​

Most likely the phone has an app with the same name from a different source (e.g. an old package downloaded from another channel). Mismatched signatures prevent installing over it; uninstall the old version first.

WARNING

Uninstalling clears local data, and the user will need to log in again.

Users don't get the update prompt? ​

Check in order:

  1. Is the master switch under "Basic Configuration → App Version Update" on?
  2. Is the "Latest version code" greater than the version the user has installed?
  3. Has the user already tapped "Later" today? After that, the prompt won't show again that day
  4. Has the user fully quit and reopened the app?

A user tapped update, but the download failed? ​

Open the configured download URL in a browser yourself and confirm it downloads. If the link itself doesn't open, the package hasn't been uploaded yet or the URL is wrong.

Funds ​

A user says their deposit hasn't arrived? ​

  1. First confirm that the chain (network) the user transferred on matches the selected coin. Assets sent on the wrong chain usually cannot be recovered
  2. Search "Deposit Records" in the admin console by UID for a matching record
  3. On-chain confirmation takes time, and confirmation speeds vary widely between chains

A user says their balance doesn't add up? ​

Pull that user's complete ledger and check it entry by entry. Every entry records the amount changed and the balance before and after, so you can pinpoint exactly which entry introduced the difference.

Don't "smooth it over" with an adjustment

When something doesn't add up, find the cause before acting. Simply adjusting the balance to a number that "looks right" makes later reconciliation harder.

Can a withdrawal be recalled after approval? ​

No. Approval sends a real on-chain transfer, which cannot be recalled once sent. Always check the address, network and amount when reviewing.

Customer service ​

A user sent a message in the app, but nothing appears in the support group? ​

Usually the group is misconfigured: the "Support group ID" must be a supergroup with Topics enabled, not a private chat; the bot must be a group administrator with "Manage Topics" explicitly ticked. For the full troubleshooting order, see Customer Service.

An agent replied in Telegram, but the user doesn't receive it in the app? ​

Messages get in but don't come back, so the problem is the callback: are both the callback URL and callback secret under "Third-Party Configuration → Live chat" filled in, and was it saved again afterwards? If either is missing, the page still says it saved successfully, but the callback is not registered.

An agent replied with a voice message, but the user didn't get it? ​

Only text, emoji and images are forwarded for now; voice messages and files are not delivered to the app.

User experience ​

A user reports the countdown doesn't match the actual settlement time? ​

Seconds-contract countdowns are based solely on the server's fixing time, and the client calibrates its clock. If the phone's system time is far off, there may be a brief visual difference, but actual settlement follows the server.

Languages are incomplete / some text is still in Chinese? ​

The user side supports 7 languages, controlled by the language dictionary in the admin console. If a new feature's text isn't translated, report it to your technical team to add it to the language pack.

Didn't find an answer?

If the issue involves a funds discrepancy, an abnormal order or a system error, please provide the user UID, time of occurrence, amount involved and app version (at the bottom of the "Me" page), and contact technical support.
